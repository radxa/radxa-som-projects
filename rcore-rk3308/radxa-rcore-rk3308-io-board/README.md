# HW Design: Radxa rCore-RK3308 IO Board

- `radxa_rcore_rk3308_schematic_v2.2.pdf`: Schematic (PDF) for quick viewing and printing.
- `radxa_rcore_rk3308_io_board.pcb`: PCB layout file (view with PADS/PADS-View on Windows).
- `radxa_rcore_rk3308_io_board_top.dxf` / `radxa_rcore_rk3308_io_board_bot.dxf`: Top and bottom DXF exports of the PCB.
- `radxa_rcore_rk3308_components_placement_map_v2.2.pdf`: Component placement map.
- `radxa_rcore_rk3308_pinout_v2.2.xlsx`: Pinout and signal table (Excel).
- `radxa_rcore_rk3308_io_board.emp` / `radxa_rcore_rk3308_io_board.emn`: Manufacturing/assembly export files.

Viewer references:

- Orcad schematic viewer (Windows): https://www.orcad.com/downloads/orcad-viewer
- PADS / PADS-View (Windows): https://community.sw.siemens.com/s/article/PADS-Viewers
